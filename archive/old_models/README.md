# Archive

Contains superseded outputs, old logs, and stale checkpoint configs that are
kept for reference but are no longer part of the active training pipeline.

| Subfolder | Contents |
|---|---|
| `audio/` | Old audio training artefacts from pre-restructure runs |
| `video/` | Old video training artefacts |
| `text/` | Old text training artefacts |
| `checkpoints/` | Stale HF checkpoint directories (config only, no weights) |
| `reports/` | Superseded markdown reports |
| `logs/` | Old training run logs |
